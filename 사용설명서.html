주요 기능 상세

1. Slack 파일 공유 (Alt + F12)

파일 탐색기에서 파일을 선택하고 Alt + F12를 누르면 Slack으로 쉽게 공유할 수 있습니다.

사용 방법:

  1. 파일 탐색기에서 공유할 파일 선택 (여러 개 가능)
  2. Alt + F12 누르기
  3. 대상 선택 (팀원 또는 채널)
  4. 자동으로 메시지 작성 및 파일 첨부!

공유 대상:

  • 팀원 DM: 안류천, 윤성원, 허혜원 등 16명
  • 채널: 사코팍-오리지널, 사코팍-일반-멤버십 등 5개

메시지 형식:

📂 파일 공유드립니다!
G:\공유 드라이브\...\경로  ← 클릭하면 폴더 열림!

┌────────────────────────────┐
│ G:\공유 드라이브\...\경로   │
│ 파일 이름: file.psd        │
└────────────────────────────┘

2. Slack 경로 링크 (Ctrl+Shift+V)

G드라이브 경로를 Slack에서 클릭 가능한 링크로 만들어줍니다.

사용 방법:

  1. 파일 탐색기 주소창에서 경로 복사 (Ctrl+C)
  2. 툴팁 확인: "경로 감지됨"
  3. Slack 채팅창으로 이동
  4. Ctrl+Shift+V 누르기
  5. 완료! 클릭 가능한 링크가 생성됨

예시:

복사한 경로: G:\공유 드라이브\JBBJ 자료실\작업물\파일.psd
    ↓
Slack에 표시: G:\공유 드라이브\JBBJ 자료실\작업물\파일.psd
              (파란색 링크 - 클릭하면 탐색기에서 열림)

3. 경로 열기 (CapsLock x2)

Slack이나 다른 곳에서 복사한 경로를 빠르게 탐색기로 열 수 있습니다.

사용 방법:

  1. 경로 텍스트를 마우스로 드래그하여 선택
  2. CapsLock 키를 빠르게 두 번 누르기
  3. 파일 탐색기가 해당 경로로 열림!

지원하는 경로:

  • G:\공유 드라이브\...
  • C:\Users\...
  • 기타 모든 Windows 경로

4. 창 고정 (Alt + `)

작업 중인 창을 다른 창 위에 항상 표시되게 고정합니다.

사용 방법:

  1. 고정하고 싶은 창 활성화
  2. Alt + ` 누르기
  3. "창이 고정되었습니다" 메시지 확인
  4. 해제하려면 다시 Alt + ` 누르기

활용 예시:

  • 참고 이미지 창을 고정해두고 작업
  • 메신저 창을 고정해두고 작업

자동 기능

자동 한영전환

지정된 프로그램(After Effects, Photoshop 등)에서 마우스를 움직이면 자동으로 영문 입력 모드로 전환됩니다.

타임 트래커

프로그램별 사용 시간을 자동으로 기록합니다. GUI 창에서 확인 가능합니다.

자리비움 감지

2분간 입력이 없으면 자동으로 자리비움(AFK) 상태로 표시됩니다.

GUI 버튼 설명

작업마법사 실행 시 나타나는 GUI 창의 버튼들:

버튼 기능
한영전환 자동 한영전환 ON/OFF
경로→링크 경로 복사 시 jbbj:// 링크 자동 변환 ON/OFF
타임트래커 프로그램 사용 시간 기록 ON/OFF
파일공유_JBBJ Slack 파일공유 기능 ON/OFF
항상위 창 고정 기능 ON/OFF

문제 해결

Q: 스크립트가 실행되지 않아요

A: AutoHotkey v1.1이 설치되어 있는지 확인하세요.

  • autohotkey.com에서 다운로드

Q: 파일 공유가 안 돼요

A:

  1. Slack이 실행 중인지 확인
  2. "Studio JBBJ" 워크스페이스가 열려 있는지 확인
  3. 파일공유_JBBJ 버튼이 ON(초록색)인지 확인

Q: 경로 링크를 클릭해도 안 열려요

A: jbbj:// 프로토콜이 등록되어 있는지 확인하세요.

  • 작업마법사를 재시작하면 자동으로 등록됩니다.

Q: CapsLock 경로 열기가 안 돼요

A: 경로 텍스트가 정확히 선택되었는지 확인하세요.

  • 경로 앞뒤에 공백이나 특수문자가 포함되면 안 됩니다.

설정 파일

설정 변경이 필요하면 설정 폴더의 파일들을 수정하세요:

파일 용도
settings.ini 경로 설정 (자료실, 설치파일 등)
alias.ini 타임트래커 프로그램 별명
program_classes.txt 자동 한영전환 대상 프로그램

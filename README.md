# JBBJ 작업마법사

JBBJ 스튜디오 팀의 작업 효율성을 높이기 위한 AutoHotkey 스크립트 모음입니다.

## 폴더 구조

```
JBBJ_AUYOHOTKEY/
├── 소스/                    # 핵심 스크립트
│   ├── JBBJ_작업도우미_배포용_v2_0.ahk   # 메인 스크립트
│   ├── JBBJ_설치도우미_1_4.ahk          # 프로그램 설치 도우미
│   └── 경로공유_UIA최종_수정1.ahk       # 파일 공유 시스템 (Slack)
│
├── 유틸/                    # 유틸리티 스크립트
│   ├── 마우스컬러_V1_4.ahk   # 컬러 픽커 (HEX/RGB)
│   ├── 돋보기.ahk           # 화면 확대
│   ├── 컷넘버입력기.ahk     # MOHO 작업용
│   ├── 피드백.ahk           # 피드백 전송
│   ├── 익명_칭찬합시다.ahk   # 익명 칭찬 (Slack)
│   ├── 오늘의운세.ahk       # 오늘의 운세
│   ├── 저녁메뉴추천.ahk     # 메뉴 추천
│   ├── 디버그.ahk           # 디버그 도구
│   └── first_setup.ahk      # 초기 설정
│
├── 게임/                    # 딴짓거리
│   ├── 스네이크게임.ahk
│   ├── 숫자야구게임_v2.ahk
│   └── 숫자게임.ahk
│
├── 설정/                    # 설정 파일
│   ├── settings.ini         # 경로 설정 (★ 경로 변경 시 이 파일만 수정)
│   ├── alias.ini            # 프로그램 별명 (타임 트래커용)
│   ├── program_classes.txt  # 자동 한영전환 대상 프로그램
│   └── config.ini           # 기타 설정
│
├── 라이브러리/              # 외부 라이브러리
│   └── UIA/                 # Windows UI Automation
│
└── 백업/                    # 구버전/백업 파일
    ├── v0/                  # v0.x 버전들
    ├── v1/                  # v1.x 버전들
    └── 기타/                # 기타 백업
```

## 주요 기능

### JBBJ 작업도우미 (메인)

| 기능 | 단축키 | 설명 |
|------|--------|------|
| 자동 한영전환 | (자동) | 마우스 움직일 때 자동으로 영문 입력으로 전환 |
| 경로 쉽게열기 | CapsLock x2 | 경로 드래그 후 CapsLock 더블탭으로 폴더 열기 |
| 파일공유 JBBJ | Alt+F12 | 선택한 파일을 Slack으로 공유 |
| AlwaysOnTop | Alt+` | 현재 창을 항상 위에 고정 |
| 바로가기 생성 | Ctrl+CapsLock | 선택한 파일의 바로가기를 클립보드에 복사 |
| 바로가기 원본열기 | Alt+I | .lnk 파일의 원본 경로 열기 |

### 타임 트래커
- 프로그램별 사용 시간 자동 추적
- 상위 5개 프로그램 실시간 표시
- 2분 이상 미입력 시 "자리비움"으로 표시

## 설치 방법

1. **AutoHotkey 설치**
   - AutoHotkey v1.1 필요
   - AutoHotkey v2 (파일 공유 기능용)

2. **폴더 복사**
   - 이 레포지토리를 G드라이브 원하는 위치에 복사

3. **경로 설정** (필요시)
   - `설정/settings.ini` 파일에서 경로 수정

4. **실행**
   - `소스/JBBJ_작업도우미_배포용_v2_0.ahk` 실행
   - 또는 바로가기를 시작프로그램에 등록

## 설정 파일 설명

### settings.ini
외부 경로를 관리하는 파일입니다. 경로가 바뀌면 이 파일만 수정하면 됩니다.

```ini
[경로]
자료실=G:\공유 드라이브\JBBJ 자료실
설치파일=G:\공유 드라이브\JBBJ 자료실\PC 설치 자료들
파일주석시스템=...
SVG변환기=...

[AutoHotkey]
AHKv2=C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe
```

### alias.ini
타임 트래커에서 프로그램 이름을 한글로 표시하기 위한 파일입니다.

```ini
[Alias]
chrome=크롬
afterfx=애프터이펙트
moho=모호
```

### program_classes.txt
자동 한영전환이 작동할 프로그램 목록입니다.

```
ahk_class AE_CApplication_25.0
ahk_class Photoshop
ahk_class Premiere Pro
```
